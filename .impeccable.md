## Design Context

### Users

Fellow software engineers, DevOps practitioners, and technical leaders looking
for practical content on Go, PHP, containers, cloud infrastructure, and AI. They
visit to read blog posts, learn about Jason's experience, and find speaking
appearances. Context: focused reading, often on desktop, sometimes mobile.

### Brand Personality

**Technical, approachable, personal.** The site should feel like a senior
engineer's personal space — competent and opinionated but warm and inviting. Not
corporate, not trying too hard.

### Aesthetic Direction

- **Tone**: Retro terminal accents (prompts, code blocks, blinking cursor) as
  personality touches, but proportional readable body text for long-form
  content. The terminal motif is seasoning, not the whole dish.
- **Reference**: Julia Evans (jvns.ca) — playful, personal, highly readable,
  no-nonsense dev blog that prioritizes content.
- **Anti-references**: Generic SaaS landing pages, dark-mode-only "hacker"
  sites, AI-generated template blogs.
- **Theme**: DaisyUI "retro" (light) + custom dark mode. Primary color
  `#3432ee`.

### Design Principles

1. **Readability first** — Blog posts are the core product. Typography must be
   comfortable for 5-10 minute reads.
2. **Terminal as accent** — Use monospace/terminal styling for code, navigation
   flourishes, and interactive moments — not for body text.
3. **Personal over polished** — Favor charm and personality over corporate
   perfection. This is a personal blog, not a product.
4. **Content-forward** — Design should disappear when reading. No visual noise
   competing with the writing.
5. **Respect the reader** — Accessible, fast, no tricks. Works for everyone.
