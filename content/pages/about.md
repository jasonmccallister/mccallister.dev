I'm a software engineer and architect. Solutions engineering is part of the job too, but the core is building and shipping software: APIs, integrations, cloud services, and the servers underneath them.

I've been doing this for more than 20 years. A lot of that has been system design, mentoring, and keeping services running in production. I care about code you can still read in a year.

## Craft Cloud

I worked with [Bref](https://bref.sh) on [Craft Cloud](https://craftcms.com/cloud), Pixel & Tonic's serverless hosting for Craft CMS. We ran PHP on AWS Lambda with Bref, Laravel for the control plane, and Cloudflare at the edge. Matthieu Napoli wrote it up as a case study: [How Craft CMS built Craft Cloud](https://bref.sh/docs/case-studies/craft-cloud).

## Uses

My tools shift when I try new things, then I usually wander back to what already works.

## IDE

I used VS Code for a long time. I moved to [Zed](https://zed.dev) recently. Language detection is good, especially on PHP projects. There's still no built-in Git GUI, though that's on the roadmap. On a MacBook Pro it feels fast.

## Terminal

I left the stock macOS zsh setup for oh my zsh when I needed features I was missing. I run [Rex](https://www.superlogical.com/rex/docs/) from [Superlogical](https://www.superlogical.com/) now. Persistent sessions and remote hosts matter more to me than another pretty prompt.

## Agentic work

I use [Cursor](https://cursor.com) for a lot of day-to-day coding with agents. Planning, refactors, tests, and digging through unfamiliar code go faster when the model can see the repo and run commands. I still review the diffs. The agent drafts; I decide what lands.

## Hardware

Day to day I use a MacBook Pro M4 Pro with 48GB RAM. I also keep a custom desktop on Pop_OS! for Linux work.
